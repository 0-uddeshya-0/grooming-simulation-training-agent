# ETHICS_NOTES (items to flag to the ethics board; draft)
- No visible timer (D-021): participants are not shown the 45-minute limit; state the maximum duration in the information sheet.
- Deception study: approval, consent framing, full debrief, post-debrief option to withdraw data.
- Sexualisation-onset ceiling: APPROVED by the ethics board (researcher meeting, 2026-11-27); wording recorded in README and `backend/constants.py`. Prohibited list includes money, identifying data, in-person meetings, pressure, self-harm. Blocked outputs are logged for the researcher.
- Abliterated model (D-017): no model-side refusals; limits enforced in code only.
- Researcher log viewer stores/reads full transcripts: special-category risk; local only, token-protected.
- Special-category data (sexual life, health, distress) in free text; pseudonymous is not anonymous; legal basis, DPIA, retention, transcript purge after debrief; deletion must cover SQLite WAL, backups, exports; full-disk encryption on the laptop.
- Age gate is self-declared: verify via recruitment; minor/age-contradiction handling is deterministic (D-010).
- Screening/warning for participants with abuse history; duty of care on real-abuse disclosures; researcher present or reachable.
- Student-supervisor power relations in recruitment.
- Helpline list must be re-verified (D-006/D-014); review youth line for an 18+ study.
- Third-party model licences (Llama 3.1 Community, Qwen, Gemma) cited in the thesis.
- Misuse: private repo, access-controlled release, use-restricted licence (D-008, D-018).
- **Data leaves the device (D-035)**: with OpenRouter, chat text is processed by OpenRouter and the model provider (Venice), possibly outside the EU; `data_collection: deny` requests no storage or training but is a request to the router, not a guarantee. The consent page states this. For examiner-only testing the risk is low; for real participants it needs board approval, a legal basis and an updated information sheet. Local mode (`model.provider: local`) restores 'nothing leaves the computer'.
- **Ceiling relaxation (D-031)**: after the board's written list, the researcher reported a later consultation in which the board agreed to allow casual in-person invitations, clothing/lifestyle/location questions, secrecy requests and an insistent register for the attacker persona (still no explicit content, images, minors, threats, money, exact identifiers, self-harm). The written record should be updated; keep the board's wording with the thesis.
- **Examiner-only testing**: the researcher states that no participants will use the artefact; supervisors and examiners will test it. If real participants are ever recruited, re-open: distress handling (`safeguards.distress_mode: end`), consent/debrief flow, and the relaxed ceiling.
- **Under-18 hard line**: a user who says they are under 18 ends the chat (the persona must never continue with a self-declared minor).
