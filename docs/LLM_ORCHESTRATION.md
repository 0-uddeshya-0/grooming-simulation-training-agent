# LLM_ORCHESTRATION
**Serving**: default `OpenRouter` client (`backend/llm.py`: spaced requests, backoff on 429/5xx, clear 401/402 errors, optional fallback models, only supported sampling parameters: top_p, top_k, presence and frequency penalties; anti-repeat raises the penalties) or `llama-server` (OpenAI-compatible, 127.0.0.1, `-c 8192`). Model, quant, sampling and the no-think switch come from `config/app.yaml`; nothing is model-specific in code.

**Prompt assembly** (`backend/prompt.py`): stable system prompt first (cache-friendly) -> last 16 turns -> a final `[DIRECTOR NOTE]` message holding the current intent, up to 3 recent user disclosures, openers to avoid, and expression hints derived from the register/offender-type scalars. The prompt describes behaviours at research level; wording is generated at runtime. It is not a safeguard (D-005).

**Sampling** (start values): temperature 0.8, min_p 0.05, repeat_penalty 1.1, presence_penalty 0.2, max_tokens 120. Tune against the repetition metric in the bake-off. Qwen3 thinking is disabled via `chat_template_kwargs.enable_thinking=false`; ``<think>...</think>` blocks are also stripped from replies before filtering.

**Per-turn pipeline** (`backend/engine.py`): STOP -> user-minor -> distress -> limit-push counter -> director.observe -> generate -> output filter (ethics ceiling rules; reasons: minor_reference, youthful_reference, explicit, meta_commentary, self_harm, pressure_or_threat, identity_request, money, meeting, roleplay; blocked text logged; <=3 regenerations, then end session `filter_exhausted`, flagged) -> anti-repetition (3-gram overlap >=0.5 vs last 6 turns, or the same 2-word opener 2x in the last 4; <=2 retries with +0.1 repeat penalty and a "vary phrasing and topic" note) -> atomic ended-check -> persist reply with tags.

**Debrief** (`backend/debrief.py`): all percentages and scalars computed in code from logged tags. The same served model only paraphrases up to two logged attacker turns per strategy; paraphrases pass the same output filter and fall back to a truncated excerpt. One llama-server is reused (no second model loaded). Percentages are *intended* exposure (stage-derived tags); validity is checked by a researcher hand-coding a sample.

## Human-likeness (D-032, D-033)
- **Persona sheet**: each persona carries `details` (consistent facts: city, job, pet, routine), `style_samples` (style only) and `fallback_lines`; all validated against the content ceiling.
- **Director plan per turn** (`Director.prepare`): focus (stage), move, length, tone words, topics the user mentioned (labels only), openers to avoid. Logged per attacker turn for the researcher.
- **Post-processing** (`filters.humanize`): strips quotes, markdown, em/en dashes and trailing stage directions, applies persona casing (lowercase personas), caps emoji at 2; replies can be split into 2-3 texts with `||`.
- **Stock-phrase filter**: customer-service/AI tells ("feel free to", "I'm all ears", ...) are blocked and regenerated with a correction.
- **Sampling** (Qwen3 non-thinking friendly): temperature 0.85, top_p 0.92, top_k 60, min_p 0.05, repeat 1.1, presence 0.5, frequency 0.2, max 100 tokens; anti-repetition adds +0.1 repeat penalty per retry.
- **Language**: participant may write German (or anything); the director note tells the persona to answer in English like someone who understands a little German; German *replies* are regenerated.
- **Never-ending replies**: filter hit -> rule-specific correction (up to 4 tries) -> in-character deflection generated by the model (3 tries) -> persona-specific fallback line (no repeats until the pool is used up). Events are logged.
